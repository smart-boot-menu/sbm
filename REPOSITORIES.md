# Smart Boot Menu — Repository Map & Boundaries

All 14 repositories under [`https://github.com/smart-boot-menu`](https://github.com/smart-boot-menu) and their strict single-source-of-truth boundaries (including dedicated `docs` and `research` repositories modeled after `0SFS`):

| Repository | Local Path | Canonical Owner Of | Must NOT Duplicate |
|---|---|---|---|
| **`.github`** | `~/gh/smart-boot-menu/.github` | Org profile, shared universal `AGENTS.md` + `agent-reference.md`, community health policies, issue/PR templates | Technical specs, ADRs, Rust code |
| **`docs`** | `~/gh/smart-boot-menu/docs` | Normative specifications (`specifications/`), ADRs (`architecture-decisions/`, 001–012), threat model, hardware profiles, 3-tier testing methodology, Mermaid diagrams | Raw ecosystem research dumps (`research`), executable Rust types/schemas (`sbm-common`) |
| **`research`** | `~/gh/smart-boot-menu/research` | Primary-source ecosystem surveys (dev infra, `SBM Manager`/flashers, Calamares/internal install, network recovery & `systemd-sysext` modularity), Apple Silicon / hardware deep dives, retained empirical benchmark/probe evidence | Normative specs/ADRs (`docs`) |
| **`sbm`** | `~/gh/smart-boot-menu/sbm` | Executive vision, architecture summary, prioritized roadmap (Tracks A–B, 0.0.1–0.0.3, 0.1–0.2), repository map, release gates, integration plan, agent prompts, handoff coordination | Duplicating full specs/research (link to `docs` & `research` instead) |
| **`sbm-common`** | `~/gh/smart-boot-menu/sbm-common` | Shared Rust crates (`sbm-types`, `sbm-protocol` `#![no_std]`+`alloc`, `sbm-schema`), canonical JSON Schemas, golden protocol test vectors | Runtime UEFI/Linux/Server business logic |
| **`sbm-uefi`** | `~/gh/smart-boot-menu/sbm-uefi` | Native Rust graphical UEFI boot manager (`x86_64-unknown-uefi`, `aarch64-unknown-uefi`, `< 1 MiB` minimal `efi-only` target), GOP renderer (`sbm-gfx`), OS/BLS/UKI discovery & policy (`sbm-boot`), interactive Track A host preview over simulated platform interfaces | Linux storage/install logic, Apple `m1n1` setup |
| **`sbm-as`** | `~/gh/smart-boot-menu/sbm-as` | Apple Silicon research integration, `m1n1` + `Asahi U-Boot` bootstrap packaging, Apple APFS/Preboot guardrails, external-boot adapters | Forking `sbm-uefi` (MUST consume standard `aarch64` `sbm-uefi` binary!) |
| **`sbm-core`** | `~/gh/smart-boot-menu/sbm-core` | `mkosi` minimal Linux image builder (Fedora Minimal `< 500 MiB` base target + Light Fedora Asahi Minimal + signed `systemd-sysext`/`systemd-confext` DDIs + minimal Linux Network-Bootstrap UKI in 0.1), recovery GUI (`labwc`+Iced `sbm-ui`+GParted), interactive Track A `sbm-ui` simulation backend, `sbm-cored` storage/install/recovery/module daemon, `wayvnc` remote bridge | Bootable media assembly (`install`), hosting multi-device dashboard (`sbm-server`), custom general-purpose package manager |
| **`install`** | `~/gh/smart-boot-menu/install` | Per-architecture (primary) & optional experimental dual-arch removable media assembly (`sbm-media`), SBM internal SSD installation (`efi-only` & `offline-full`)/uninstall/boot-repair planner & executor (`sbm-plan`, `sbm-exec`), guided partition-resize planner (0.0.3), TUF/A-B updater (`sbm-release`), flasher feed (`sbm-os-list.json`) & **`SBM Manager`** desktop provisioning/configuration integration (0.0.3–0.1+), BitLocker & Apple pre-flight safety gates | Installing third-party OSes like Windows/Ubuntu/BSD (`sbm-core`), reinventing mature CLI partition/FS tools (`ADR-006`) |
| **`sbm-server`** | `~/gh/smart-boot-menu/sbm-server` | Optional self-hosted management server (`axum`/`sqlx`), SvelteKit web dashboard (`noVNC`/`xterm.js`), Passkeys/RBAC, device enrollment, ephemeral remote-recovery session relay (0.1), Ed25519 command signing, audit log | Mandatory cloud dependency; protocol schema redefinition |
| **`sbm-catalog`** | `~/gh/smart-boot-menu/sbm-catalog` | Declarative OS catalog entries, verified mirror metadata, hardware/platform compatibility tags, schema validation CI, TUF signing/publishing pipeline | Arbitrary executable install scripts; OS installer implementation (`sbm-core`) |
| **`sbm-agent`** | `~/gh/smart-boot-menu/sbm-agent` | Optional guest OS background daemon (Linux/Windows/macOS): boot-success confirmation, health reporting, authorized remote reboot / one-shot handoff | Full bare-metal recovery or partitioning (`sbm-core`) |
| **`sbm-lab`** | `~/gh/smart-boot-menu/sbm-lab` | macOS multi-agent host memory-admission guard (`resources.rs`), thin macOS HVF UEFI smoke/integration runner, disposable Tier 2 QCOW2 multi-OS disk fixtures, fault injection, and Linux CI (`os-autoinst` / U-Boot `sandbox` / future `labgrid`) glue | Production runtime code; duplicating `sbm-media` GPT/FAT32 writers or reinventing mature Linux VM/CI frameworks (`ADR-010`) |
| **`smart-boot-menu.github.io`** | `~/gh/smart-boot-menu/smart-boot-menu.github.io` | Official public website, user documentation portal, **`SBM Manager`** & verified per-arch download index, and evidenced Tier 3 compatibility matrix | Canonical technical specs (pull/link from `docs` & `sbm`) |
