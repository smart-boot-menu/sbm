**Target Hardware:** Older x86-64 HP laptop (`EXP-HW-HP01`, per [`docs/hardware/target-hardware.md`](../../docs/hardware/target-hardware.md))  
**Target Artifact:** `/Users/felg/gh/smart-boot-menu/install/build/qual-0.0.1/x86_64/sbm-0.0.1-uefi-x86_64.raw.zst`  
**Expected Compressed SHA-256:** `4f825fc1eaedebe6cf2436a3ea33613c4be9879e7e950de313d11e115a23381e` (`896,237,084 B`)  
**Expected Raw SHA-256:** `9bebf042be7c79feea29d2080c192ea50133d74fb29612545356b1e23756a378` (`1,120,927,744 B`)  
**Testing Tier:** **Tier 3 — Explicitly Authorized Physical Hardware (Strictly Manual / Opt-In)**

> **ABSOLUTE SAFETY RULES (READ BEFORE STARTING):**
> 1. **DO NOT** run any destructive disk, partition, or format operations on the HP laptop's internal SSD/HDD during this test. GParted is opened strictly in **read-only inspection mode** — do NOT click *Apply*.
> 2. **DO NOT** flash, erase, or modify the macOS workstation's internal NVMe, NVRAM, SIP, or `LocalPolicy`. Double-check the target USB device size and name before flashing.
> 3. **Back up or confirm** any important data on the HP laptop before changing UEFI Secure Boot or Boot Order settings, and note existing UEFI settings so you can restore them cleanly after testing.

## Phase 4 — SBM Core Graphical Recovery Verification (`sbm-core@960f11a`)

- [ ] **4.1 Desktop & `sbm-ui` Render Check:** Confirm `labwc` + Iced `sbm-ui` renders cleanly with readable text and mouse/touchpad/keyboard control.
  - Note **Renderer** line shown in `sbm-ui` (`wgpu` hardware GPU vs. `software (tiny-skia)` fallback): `________________`
  - Note **Root mode** line: must read **`backing-protected`**.
  - Note **Handoff** line: must show **`(hash verified) [integrated EFI handoff]`**.
  - Note **Memory** line: `________ total, ________ available`.
  - Note **Status** in sidebar: must show **`desktop ready (confirmed <uuid>)`**.
- [ ] **4.2 GParted Inspection (READ-ONLY — DO NOT APPLY CHANGES):**
  - Click **Open GParted** in `sbm-ui`.
  - Confirm GParted launches cleanly over XWayland.
  - Open the top-right device selector and confirm both the SBM USB drive and the internal drive appear accurately.
  - Confirm the SBM USB boot disk is read-only protected while GParted is open.
  - Close GParted **without making any edits**.
- [ ] **4.3 Read-Only Hardware Characterization Probe (`EXP-HW-HP01`):**
  - Click **Open terminal** in `sbm-ui` and collect hardware facts (save to a temporary file or photograph; **redact serial numbers, UUIDs, and MAC addresses** before committing to `research/hardware/hp-laptop-profile.md`):
    ```bash
    uname -a
    lscpu | grep -E 'Model name|Architecture|CPU\(s\)|Flags'
    free -h
    lspci -nnk | grep -A3 -E 'VGA|3D|Display|Network|NVMe|SATA|USB'
    lsusb
    lsblk -o NAME,SIZE,TYPE,TRAN,RO,MODEL
    efibootmgr -v
    cat /sys/firmware/efi/efivars/SecureBoot-* 2>/dev/null | od -An -tx1 || true
    cat /sys/firmware/efi/efivars/SetupMode-* 2>/dev/null | od -An -tx1 || true
    dmesg | grep -iE 'efifb|simpledrm|drm|i915|amdgpu|nouveau|i2c|hid|iwlwifi|rtw|ath|brcm|verity|SBM_PROTECT' | head -n 60
    ```
  - *(Optional check for Microsoft 2011 vs. 2023 UEFI CAs for future SBM 0.2 Secure Boot work:)*
    ```bash
    mokutil --sb-state 2>/dev/null || true
    efi-readvar -v db 2>/dev/null | grep -iE 'Microsoft|UEFI CA' || true
    ```
- [ ] **4.4 Clean Reboot & Attempt Confirmation:**
  - Click **Reboot** in `sbm-ui` (do NOT force power-off).
  - Boot the SBM USB drive via `F9` one more time to verify post-reboot menu renders cleanly (confirming `boot-success.json` reconciliation).
- [ ] **4.5 Existing OS Chainload / Clean Restoration:**
  - Either select the HP laptop's existing OS from SBM's menu (optional chainload test) OR choose **Shut down**, unplug the SBM USB drive, re-enable Secure Boot in HP UEFI Setup if it was previously enabled, and verify the HP laptop boots its original installed OS identically to before testing.
